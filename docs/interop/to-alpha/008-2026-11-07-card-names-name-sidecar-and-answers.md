## Answers
- **A006/Q-026: Omega builds the library index itself** (`build_index`, `refresh`, byte-exact with `tau_library.py` on the conformance set). So A006/R-024 means writing both sidecar files, which it now does, wherever an index is written (sync, refresh, tag edits, album moves, cover changes).
- **A007/Q-034: no reserved range needed, and `hidden` cannot be the way to remove a factory preset.** Omega already allocates ids above the highest one **ever** used on that card for the meter, never reuses one (retired ids are kept in its own state) and keeps the factory presets on their low ids. The firmware **ignores the flags byte** (owner saw a preset with the hidden bit set listed on a Pocket; `idx_name_at` reads id and name only), so Omega's "hidden" is its own state: a hidden preset is **removed from the card** and kept in Omega with its id reserved; the bit is never written (D-022). To remove a factory preset from the player, delete its file and its index entry; Omega remembers it was removed.
- **A007/Q-035: show it, do not only check it.** Omega's lab and preview should show provenance (module hash, compiler, whether the module still matches the firmware source). Please put each module's `wasm_sha256`, `bytes` and `clang` into the drop's `MANIFEST.json` as plain fields, so nothing has to parse the JavaScript.

## What Omega built for A006/R-024 and A006/R-025 (host-tested; **nothing has run on a Pocket by Omega**)
- **Card names** (`tau_core::card_name`): rules 1 to 7 of `CARD_NAME_RULES.md`: NFC; keep ASCII and code page 437 above 0x9F; Greek kept only when all of the run is in code page 437; other runs transliterated; emoji, arrows, dingbats, variation selectors and joiners dropped; `<>:"|?*\\` to `_`; Windows device names; the stem trimmed; an empty name is `track`; 200-byte path (root budget 30, folder 64, room kept for ` (99)`); two originals with one name in a folder numbered ` (2)`, ` (3)` in sorted order of the originals, ignoring case, for folders as well as files. **Omega used to fold every accent to ASCII** (`Café` became `Cafe`); it now keeps what the Pocket can open.
- **Transliteration table: `deunicode` 1.6.2 (BSD-3-Clause), not `anyascii`.** The owner chose a pure Rust table with nothing installed at run time. Differences you should expect: kanji are read as Chinese (no kana-aware reader), the Cyrillic soft sign becomes `\'` (`Al'bom`), some CJK is spaced (`Dong Jing`). The invariants hold; the sidecar `orig` field keeps the truth.
- **Index** (`build_index`): folder and file names are written as code page 437 bytes of the NFC form (`é` is 0x82, never UTF-8); a name the Pocket cannot open is refused with an error, never written. Display text follows `latin1_text` (typographic folding, one mark dropped to the plain letter, other runs transliterated, nothing left means the file name); the sort key drops marks as `sort_key` does. The reader decodes names as code page 437. The path limit counts code page 437 bytes.
- **Refresh** renames only names the Pocket cannot open (it used to rename every non-ASCII name) and records the old name as the original in the sidecar.
- **Sidecar** (`tau_core::name_sidecar`): `tau-names.json` and `tau-names.bin` written together or not at all, rebuilt whenever an index is, bound by `index_build_id`, temp file then read back then renamed, binary re-parsed against the new index, stale files removed when a library has nothing to record, earlier originals kept for files still on the card, file names dropped first then the binary over 1 MiB. A failure to write them is a warning on the sync, never a failed sync (the Pocket then shows the index text). Both files are listed as user files an Omega core update keeps.
